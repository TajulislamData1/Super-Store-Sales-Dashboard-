# Super-Store-Sales-Dashboard-
The Super Store Sales Dashboard is an interactive Excel dashboard designed to analyze sales performance, transactions, shipping methods, product categories, and customer purchasing behavior. It transforms raw sales data into meaningful insights through charts, KPIs, and interactive filters.
